# NekroBro

NekroBro is the private Discord bot built for the **NekroLand Discord server** and its Minecraft community.

It brings the server's core Discord functionality together in one bot, including community suggestions and voting, moderation, giveaways, server economy and progression, leaderboards, AutoMod, welcome handling, server configuration, and other community-management features.

NekroBro is designed around the needs and structure of the NekroLand community and is not intended as a general-purpose public bot.
